# CozyUni — World Bible v0.1

Status: foundation draft for product/world development.

## 1. High concept

CozyUni is a connected cozy universe where a small cast of expressive animal residents lives across villages, forests, markets, rivers, workshops, seasonal festival grounds, and future regions. Each game mode is a different activity in the same world rather than a disconnected product.

The player's relationship with the world should feel persistent: the same residents, same home village, same shops, same festivals, and the same collection/progression identity appear across modes.

## 2. Core fantasy

The player belongs to a friendly community that is always preparing, building, delivering, exploring, celebrating, and helping one another. Competition exists, but it is playful and readable rather than destructive.

Core emotional pillars:
- belonging
- preparation and anticipation
- small mastery loops
- visible community progress
- light rivalry
- collection and personalization
- seasonal return reasons

## 3. Anchor location: Moonberry Village

Moonberry Village is the first hub and visual identity anchor.

Residents:
- Rabbit — player-facing energetic resident
- Poppy — bear
- Milo — dog
- Lumi — cat
- Mayor Pip — hedgehog mayor / festival coordinator

Key shops:
- Bakery
- Farm Shop
- Fish Shop
- Lantern Shop
- Fabric / Ribbon Shop
- Wood Workshop
- Flower Shop
- Gift Shop

Central objective location:
- Mayor House / Festival Hall

The village should remain recognizable across game modes. Modes may change lighting, event dressing, interactable props, route rules, and temporary objectives, but should reuse a common canonical map and asset IDs where practical.

## 4. World expansion model

CozyUni expands by adding **districts/regions**, not by replacing the existing village.

Possible future regions:
- Moonberry Village — festival/community core
- Firefly Meadow — night collection and exploration
- Mossbell Woods — light adventure and gathering
- Brookside Market — trade, delivery, timed orders
- Cloudberry Hills — traversal, races, seasonal sports
- Seaside Cove — fishing and water-themed activities
- Snowbell Hamlet — winter events

A new region should justify itself with at least one new primary activity, one new visual biome, and reusable assets for multiple future modes.

## 5. Shared world systems

These should belong to the universe rather than individual modes:
- player profile
- character ownership / selection
- cosmetics
- wardrobe/accessories
- achievements
- collection book
- seasonal calendar
- currencies if introduced
- settings/accessibility
- localization
- save/account layer
- friend/lobby identity
- analytics/telemetry vocabulary

Mode-specific score systems such as Festival Stars should not automatically become global currencies.

## 6. Tone rules

- cozy, optimistic, readable
- conflict is playful, not cruel
- no grim stakes
- failure produces partial success, learning, or humorous recovery where possible
- NPCs do not shame the player
- competitive modes can have winners without making the world hostile

## 7. Visual canon

- premium stylized 3D
- soft rounded silhouettes
- readable mobile shapes
- hand-painted/PBR feeling
- controlled pastel palette
- shops and characters carry hierarchy over background decoration
- environment clutter is restrained
- UI uses warm cream/parchment, restrained green highlights, clean icons, and high readability

## 8. Product rule

Every new mode must answer:
1. Which existing assets/systems does it reuse?
2. What is the genuinely new player verb?
3. Why should an existing CozyUni player care?
4. Does it deepen the world, or merely duplicate content?
5. Can it be measured independently for fun and retention?

If a proposed mode cannot answer #2, it should probably be an event/variant rather than a new mode.
