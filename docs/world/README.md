The old blanket rule `do not build the world now` is superseded for a narrow milestone.

Allowed now:
- build a basic walkable world visual MVP;
- exactly eight small maps/regions;
- strong environmental detail and readable routes;
- simple walking/camera/collision/travel;
- create two canonical reference images per world map;
- create two canonical reference images per each of the five game boards;
- generate standalone 3D assets through the locked local prompt + reference + Tripo pipeline.

- crafting/farming economy;

- house interior/decorating system;
- persistent online/shared world.
