# CozyUni — Game Mode Roadmap v0.1

## Guiding rule

Reuse the same world, characters, shops, props, animation library, UI system, and save/profile layer. A new mode must introduce a new primary verb or a clearly different decision structure.

## M0 — Festival Board

Status: flagship / most developed.

Core:
- clockwise board movement
- quests and deliveries
- Festival Stars
- Spotlight shops
- Contracts
- cooperative festival completion + individual Champion

Purpose:
- establishes the world
- establishes the four residents
- creates the canonical Moonberry map/shop identities

## M1 — Festival Rush

Recommended first quick-win expansion.

Session: ~2–4 minutes.

Core verbs:
- run
- collect
- route
- deliver
- combo

Loop:
1. Receive a 2–3 item order.
2. Navigate Moonberry in real time.
3. Collect from shops.
4. Deliver to Mayor / event station.
5. Chain deliveries for score multiplier.

Reuse:
- four characters
- full village
- 8 shops
- item icons/models
- Mayor Pip
- delivery VFX
- ranking/end screen

New engineering:
- real-time movement controller
- order scheduler
- pickup triggers
- combo timer

## M2 — Firefly Catch

Session: ~2–3 minutes.

Core verbs:
- explore
- collect glowing fireflies
- decide when to bank them

Risk/reward:
- carry more = multiplier rises
- deposit safely at Lantern Shop/Festival Hall
- light hazards may make the player drop part of the carried fireflies

Reuse:
- Moonberry map
- night lighting variant
- four characters
- Lantern Shop
- collection HUD

New assets should be minimal:
- firefly particle/VFX
- night grading
- rare firefly variants

## M3 — Delivery Dash

Session: ~3 minutes.

Core:
- sequential parcel delivery between existing shops/NPCs
- shortest-route decisions
- shortcut and terrain knowledge
- first-delivery / streak scoring

Reuse is extremely high; useful as a low-cost competitive mode.

## M4 — Shop Panic

Higher-cost expansion after simpler modes prove retention.

Core:
- shops continuously generate requests for goods from other shops
- players decide which orders to accept
- timed fulfillment
- combo / priority queue

Fantasy: light logistics chaos, not cooking simulation.

Potential depth:
- urgent orders
- bundled route planning
- temporary shop bonuses
- team mode

## Event variants

Prefer variants over permanent new modes when only presentation/rules change:
- Firefly Night
- Harvest Festival
- Winter Lights
- Spring Bloom
- Moonberry Anniversary

## Mode production order

Recommended:
1. Festival Board
2. Festival Rush
3. Firefly Catch
4. Delivery Dash
5. Shop Panic

Do not build all five before launch. The roadmap describes reusable opportunities, not a launch checklist.
